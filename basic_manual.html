1. What it is

PX-BASIC turns the PX-42F into a small computer you program in BASIC, the language of the first home computers. It follows Palo Alto Tiny BASIC, from 1976: numbered lines, PRINT, INPUT, IF, GOTO, GOSUB, FOR. To that it adds the calculator itself:

  • Its numbers. 34-digit decimals, from the library Plus42 computes with. 0.1+0.2 is exactly 0.3, and SIN, LOG and SQR have the calculator's precision.
  • Its screen, keys and speaker. Lines and points, the keys as input, the calculator's tones.
  • Its drive. Programs are saved as text files that a computer can open too.

2. Getting started

Installing

  1. Make sure the calculator's firmware is the PX-42F-Plus with app API version 3 or later.
  2. On the calculator, open Settings → USB Drive → Connect to Computer.
  3. Copy BASIC.bin into BIN/APPS on the drive named PX-42F. From the project folder, make install does it.
  4. Optionally, copy the example programs (.BAS files, in the project's sim/drive/BIN/APPS/BASIC/) into BIN/APPS/BASIC on the drive.
  5. Eject the drive and press EXIT on the calculator.

Starting and leaving

Start it from Settings → Games & Apps → Apps → BASIC. It shows how much room there is for a program, then the prompt, >.

To leave, press ON at the prompt. The status bar asks LEAVE BASIC? ENTER=YES: ENTER (or ON again) goes back to the list of apps, and any other key stays in BASIC. Held for 2 seconds, ON turns the calculator off without asking, and the Sleep Timer does too.

The program you were working on is saved when you leave, as AUTOSAVE.BAS, and comes back the next time you start BASIC.

Your first program

BASIC keeps lines that start with a number, in number order, as the program. A line without a number runs at once. Type these three lines, pressing ENTER after each. Use the keyword map (SHIFT ▼, below) for FOR, PRINT and NEXT, and SHIFT ENTER (ALPHA) to switch between letters and digits:

10 FOR I=1 TO 5
20 PRINT I,SQR(I)
30 NEXT

Then type RUN (or choose it from the keyword map): it prints each number and its square root. LIST shows the program again.

The keyword map

Typing RETURN letter by letter takes six keys. SHIFT ▼ shows a map of BASIC's words laid over the keys: press a key to type its word, with the space or ( after it. ▼ again shows the second page, the functions. ▼ once more, ON (shown as BACK), or a key with no word on it (an empty box), goes back without typing anything.

RUN is on two keys of the first page: ENTER's place, with the other commands, and R/S's place on the bottom row, the same key as SHIFT R/S, which runs the program without the map.

Typing from a computer

With the calculator connected by USB, open its console port ("PX-42F Console") in any terminal program; the speed setting doesn't matter. A Mac lists it with ls /dev/cu.usbmodem* (the first of two); screen /dev/cu.usbmodem2101 opens it. Then:

  • What you type there goes to BASIC as if typed on the keys, in any case: lowercase becomes uppercase, except inside quotes.
  • Paste a whole program: each line goes in as typed.
  • Everything the screen shows also goes to the terminal, so a long listing can be read there.
  • Ctrl-C stops a running program, as R/S does; at the prompt it clears the line.
  • The arrow keys work as you'd expect: ← → move in the line, Home and End go to its ends, Delete deletes under the cursor, ↑ ↓ step through the history. Ctrl-A Ctrl-E Ctrl-B Ctrl-F Ctrl-P Ctrl-N and Ctrl-U do the same, for terminals that don't send the arrows.
  • Editing the middle of a line redraws it with ANSI codes (carriage return, clear to the end of the line, cursor back): any ordinary terminal handles them. If CoolTerm shows odd characters or never sends the arrows or Ctrl-C, set it to Raw Mode (Connection → Options → Terminal), which sends each key at once.

4. Writing a program

  • A line with a number (1 to 32767) goes into the program. Lines are kept in number order, whatever order they're typed in. Number them in tens (10, 20, 30) to leave room for lines in between.
  • The same number again replaces that line. The number alone deletes it.
  • A line without a number runs at once: PRINT 2^64, or RUN.
  • Several statements fit on one line, with : between them: 10 X=1:Y=2:PRINT X+Y.
  • A line holds up to 80 characters, more than the screen's 31: the text wraps.
CommandDoes
RUNRuns the program from its first line, with every variable set to 0. SHIFT R/S does the same without typing it; so does the R/S key's place in the keyword map, which types RUN for ENTER.
LISTShows the whole program. LIST 100: from line 100 on. LIST 100,200: lines 100 to 200. R/S stops a long listing.
NEWErases the program and the variables.
GOTO 100Typed at the prompt: runs from line 100 without clearing the variables.

Editing the program

You don't have to retype a line to change it. On the calculator, ▲ or ▼ at an empty prompt opens the program editor. It works in two steps, on one screen:

  1. The list. The program is shown a line to a row, the current line highlighted, and the header says PROGRAM. It opens on the line you last entered, or on the last line. ▲ and ▼ move the highlight, and the list scrolls; SHIFT with them moves a screenful. ENTER starts editing the highlighted line. EXIT (the ON key) leaves the editor, back to the prompt.
  2. Editing a line. The line is edited where it is, in the list: all of its text, as many rows as it needs, with the rest of the program still shown around it. The header says EDIT and what the keys do. ▲ moves the cursor left and ▼ right (the cursor is the white block). What you type goes in at the cursor; ← deletes the character before it; SHIFT ← clears the line; SHIFT ▼ is the keyword map; SHIFT ENTER switches ALPHA and NUM (the header then says NUM).
    • ENTER accepts the change: the line replaces the old one.
    • EXIT discards it: the line stays as it was.
    Either way you're back at the list, on the same line, to move to another one.
  • A new line from an old one: change the number while editing. The edited line goes in under the new number, and the old line stays.
  • Deleting a line: edit it down to just its number and press ENTER. The line is removed, and the highlight moves to its neighbour.
  • A line with no number (the number edited away) is dropped as if discarded: it would run as a command, which isn't what you meant.

The history is on SHIFT ▲: it brings back the last command typed, for running it again. At a program's INPUT, ▲ and ▼ only move in what you've typed.

5. Numbers

Every number is a decimal of up to 34 significant digits, from ±10−6143 to ±106144, the same numbers Plus42 computes with. Because they're decimal, the sums that go wrong in most computer languages come out right: 0.1+0.2 is exactly 0.3. A fraction with no exact decimal still rounds, as on any calculator: 1/3 is 0.333…3, 34 threes.

How PRINT shows them

  • Rounded to 12 significant digits, like the HP-42S's display. DIGITS n changes that, from 1 to 34. After DIGITS 34, PRINT SQR(2) shows 1.414213562373095048801688724209698.
  • No zeros at the end: 2.50 prints as 2.5.
  • With E when the number is too large for the digits, or below 0.000001: 1.5E-7, 6.02214076E23.
  • The number is kept to all 34 digits; DIGITS only changes how it's shown.

Writing them

12, -3.5, .25, 2E-3, 6.02214076E23. An E is the exponent only with digits after it, so 2*E is two times the variable E.

Variables and the array

  • Variables: 26, A to Z, one letter each. They start at 0, and RUN sets them to 0.
  • The array: @(0) to @(1023), for lists and tables: @(I)=I*I.

8. The screen, sound and keys

Text

The text fills 9 lines of 31 characters under the status bar, and scrolls up when it reaches the bottom.

  • CLS clears the screen and puts the text cursor at the top left.
  • AT col,row moves it, from 0,0 to 30,8, for the next PRINT.

Graphics

The screen is 250 × 122 pixels, with x from 0 (left) to 249 and y from 0 (top) to 121. A colour of 1 is black (the default), 0 white, which erases.

StatementDraws
PSET x,y or PSET x,y,cone pixel
LINE x1,y1,x2,y2 (,c)a line
BOX x,y,w,h (,c)a filled rectangle w wide, h high, from its top-left corner

Drawing and text share the screen. While a program runs the status bar isn't redrawn, so the program can use the whole screen; it comes back at the prompt.

Sound and time

  • TONE n plays the calculator's tone n, 0 (low) to 9 (high), or 10 for the error sound. The program waits until it has played.
  • WAIT ms pauses that many milliseconds; R/S still stops the program during it.

Keys: KEY()

9. Saving programs

Programs are saved on the calculator's drive as plain text files, NAME.BAS, in the folder /BIN/APPS/BASIC/. A name has up to 20 letters, digits, _ or -. The quotes can be left out: LOAD RINGS3D is LOAD "RINGS3D". Inside quotes a name can also have spaces: SAVE "My Ring"; without quotes a name ends at the first space. The SAVE, LOAD and ERASE keys of the keyword map type the word and a space, no quote. Lower case is the same name in capitals: "Ring_3d" is saved and listed as RING_3D.

CommandDoes
SAVE "NAME"Saves the program, replacing a saved one of that name.
LOAD "NAME"Loads a saved program, in place of the one in memory.
FILESLists the saved programs.
ERASE "NAME"Deletes a saved program.

On a computer. In USB Drive mode the files are in BIN/APPS/BASIC. A .BAS file is the program as LIST shows it, so you can read and write programs in any text editor. Lines without a number are skipped when loading.

AUTOSAVE. When you leave BASIC, the program in memory is saved as AUTOSAVE.BAS, and loaded again when BASIC starts. It's the program as it is at that moment, whatever you saved or loaded under other names meanwhile: after LOAD "GAME" and leaving, BASIC starts with GAME. It's written when you leave by ON (and ENTER to confirm), when you hold ON to turn off, and when the Sleep Timer or an empty battery turns the calculator off. It isn't written if the calculator crashes or is reset, so SAVE a program you can't lose. FILES doesn't list it.

10. Errors

The three messages of the original Tiny BASIC, plus BREAK. In a program each also says the line: HOW? IN 120.

MessageMeansFor example
WHAT?It can't be read.a misspelling (PRIMT), a missing ) or =
HOW?It can't be done.division by zero, SQR(-1), GOTO a line that isn't there, RETURN without GOSUB, @(5000), LOAD a file that isn't there
SORRYThere's no room.the program is full (16 KB), or GOSUBs and FORs nest more than 32 deep
BREAKR/S, ON or Ctrl-C stopped it.

10 REM GUESS THE NUMBER, 1 TO 100
20 N=RND(100):T=0
30 INPUT "GUESS? ",G
40 T=T+1
50 IF G<N THEN PRINT "HIGHER":GOTO 30
60 IF G>N THEN PRINT "LOWER":GOTO 30
70 PRINT "YES, IN ";T;" GUESSES"
